This section presents the training loss curve after incorporating class-conditioning on top of temporal conditioning, along with specific category-specific digit images generated using Classifier-Free Guidance (CFG). By injecting class labels into the UNet and combining this with a Dropout strategy, the model gained the capability to generate specified digits.

This section also documents the experimental process and final comparison of generated results when using Constant Learning Rate to maintain model performance after removing the Exponential LR Scheduler.

It can be observed that fixing the learning rate at 1e-3 results in a faster initial loss decline. This demonstrates that a smaller learning rate more readily locates the correct convergence interval, whereas a larger learning rate tends to miss the narrow convergence interval, consequently slowing down training.
